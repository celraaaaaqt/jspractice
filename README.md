# JavaScript Fundamentals 🚀

This repository documents my journey learning the core concepts of JavaScript. It contains notes, code snippets, and small exercises I'm working through as I build a solid foundation in the language.

## 📌 About

I'm learning JavaScript from the ground up — starting with the basics and working toward more advanced topics. This repo serves as both a study log and a reference I can come back to.

## 📚 Topics Covered

- [ ] Variables (`var`, `let`, `const`)
- [ ] Data Types (strings, numbers, booleans, null, undefined)
- [ ] Operators (arithmetic, comparison, logical)
- [ ] Conditionals (`if`/`else`, `switch`)
- [ ] Loops (`for`, `while`, `do...while`)
- [ ] Functions (declarations, expressions, arrow functions)
- [ ] Arrays and array methods (`map`, `filter`, `reduce`, etc.)
- [ ] Objects and object methods
- [ ] Scope and closures
- [ ] `this` keyword
- [ ] Template literals
- [ ] Destructuring
- [ ] Spread/rest operators
- [ ] ES6+ features
- [ ] Asynchronous JavaScript (callbacks, promises, `async`/`await`)
- [ ] DOM manipulation
- [ ] Event handling
- [ ] Error handling (`try`/`catch`)
